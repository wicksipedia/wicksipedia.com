Wicksipedia — five design directions

Static previews built with the real site content (titles, dates, tagline, and the git-and-diffs post). Each page shows the homepage treatment, then the post page treatment.

Every preview has a working light/dark toggle in its header — check both; two of the directions invert their whole conceit between modes.

  1. 1 Phosphor The site is a terminal session — tmux chrome, ls -la index, blinking cursor; light mode is a tractor-feed printout.
  2. 2 Runbook Every post is a controlled engineering document — doc-control header, numbered sections, EXHIBIT panels; light is a spec sheet, dark is a blueprint.
  3. 3 The Wicksipedia Review A technical periodical — masthead, lead story with a big italic serif headline, numbered TOC, drop caps, margin pull quotes; no cards, no thumbnails.
  4. 4 Control Plane The blog as an instrumented pipeline — segmented progress bar, status semantics, ISO timestamps, a ledger table instead of cards, sticky TOC rail.
  5. 5 Two-Ink A risograph zine about pipelines — two inks, overprint offsets, rotated stamps, squiggle rules; code and screenshots stay full-colour in taped-on frames.
